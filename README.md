# AI-Emotion-Detection-System
Real-Time Emotion Detection using Python, OpenCV and FER

Developed by: Akhil Gautam.

## Features
- Real-Time Emotion Detection
- Face Detection
- Emotion Confidence Percentage
- Screenshot Capture
- Pause/Resume
- Emotion Log CSV

## Technologies Used
- Python
- OpenCV
- FER
- TensorFlow

## Controls
- SPACE = Pause / Resume
- S = Save Screenshot
- Q = Quit

## Detected Emotions
- Happy
- Sad
- Angry
- Fear
- Surprise
- Disgust
- Neutral
